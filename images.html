Images

Images are used a lot in web design because they help add meaning, show information, and make pages more interesting. In web development, images can be added directly in HTML or used in CSS as background images.

Using an img Tag vs background-image

The img tag is used when the image is part of the actual content of the page. For example, if you are showing a photo, logo, or picture that matters to the meaning of the page, you would usually use HTML like this: 

<img src="baseball.jpg" alt="Baseball field">

A background image is usually more for design and layout. Instead of being placed directly in the content, it is added with CSS to an element like a div or section. The code looks like this: 

background-image: url("english-bulldog.avif");

One difference in code is that the img tag goes in the HTML, while background-image is written in CSS. Another difference is that an img element is actual page content and can include alt text for accessibility, while a background image is usually decorative. Background images are also easier to control with layout features like positioning, repeating, and covering the full area of a box.

Other CSS Properties for Background Images

Besides background-image, other CSS properties can change how a background image looks. One is background-size, which controls how large the image appears. For example, cover makes the image fill the entire box. Another is background-repeat, which decides if the image repeats across the space or only appears once. A third useful property is background-position, which controls where the image is placed inside the element.

Dimensions vs Resolution

Dimensions are the width and height of a bitmap image in pixels, while resolution describes how much detail the image contains within those pixels.

Image File Formats

GIF, PNG, JPG/JPEG, WebP, and SVG are all common image formats, but they work differently. GIF supports simple animations but has limited color quality. PNG works well for graphics and images that need transparency. JPG or JPEG is usually best for photos because it compresses images into smaller file sizes. WebP is a newer format that often gives good quality with even smaller file sizes. SVG is different because it is a vector format, meaning it can scale without becoming blurry.

Some formats are better depending on the use. JPG is typically best for photographs. PNG works well for logos and graphics that need transparency. GIF is useful for short animations. WebP is good for websites because it keeps images small while still looking good. SVG is ideal for icons and illustrations that need to stay sharp at any size.
