CSS Media Queries

A media query lets a website change its layout depending on screen size. This helps websites work better on phones, tablets, and computers.

They are useful because different devices have different screen sizes, and media queries make the site responsive.

Media Features

max-width: applies styles when screen is smaller than a certain width.

min-width: applies styles when screen is larger than a certain width.

orientation: detects portrait or landscape screen.

max-height: applies styles when screen height is smaller than a certain size.
