CSS Media Queries

How media queries work and why they are useful

A CSS media query lets a website change its layout depending on the screen size or device. It checks conditions like screen width, and if the condition is true, it applies different styles.

Media queries are useful because people view websites on phones, tablets, and computers. Without media queries, a website might look good on a laptop but bad on a phone. Media queries help make websites responsive so they adjust automatically.

Media Features

max-width: This applies styles when the screen is smaller than a certain width. This is commonly used for phones so layouts fit better.

min-width: This applies styles when the screen is larger than a certain width. This is useful for laptops and desktops where there is more space.

orientation: This detects whether the screen is portrait (tall) or landscape (wide). This helps adjust layouts depending on how the device is held.

max-height: This applies styles when the screen height is smaller than a certain size. This helps content fit better on shorter screens.

Code Example

@media (max-width: 600px) {
  body {
    background-color: lightgray;
  }
}

This example changes the background color when the screen width is 600px or smaller.
