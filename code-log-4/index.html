CSS Color

CSS uses color to control how text, backgrounds, and borders look on a webpage. It helps with readability and also makes stuff look less boring.

CSS Color Properties

color

The color property changes the color of text.

p {
  color: blue;
}

background-color

The background-color property changes the background behind an element.

body {
  background-color: lightgray;
}

border-color

The border-color property sets the color of an element’s border.

div {
  border: 2px solid red;
  border-color: red;
}

Ways CSS Accepts Color Values

Named

Named colors are simple words like red, blue, green. Easy, but limited.

h1 {
  color: red;
}

Hexadecimal

Hex colors start with # and usually have 6 characters (RR GG BB).

h2 {
  color: #3498db;
}

RGB

RGB uses numbers 0–255 for red, green, and blue.

p {
  color: rgb(255, 0, 0);
}

Other format: HSL

HSL stands for hue, saturation, and lightness. It’s nice for tweaking colors.

li {
  color: hsl(120, 60%, 40%);
}

Overall, CSS gives you a bunch of ways to set colors, so you can be simple (named colors) or super specific (hex/rgb/hsl).
