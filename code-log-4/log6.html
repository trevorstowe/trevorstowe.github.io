Code References

For this code log, I looked up the CSS property display. I picked this because it is used a lot in web design and it changes how elements show up on a page. It can make something act like a block, stay inline, or even disappear. Since it affects layout so much, it seemed like a good thing to compare across different code reference websites.

Sources I Used

  • MDN Web Docs, display
  • W3Schools, CSS display Property
  • CSS Tricks, display
  • freeCodeCamp, display article

What was different on each site?

All four sites explained the basic idea of the display property, but they did it in different ways. MDN felt the most detailed and technical. It listed a lot of values and gave more complete explanations, so it seemed really useful once you already kind of know what you are doing. W3Schools was a lot more simple and direct. It got to the point fast and made it easy to see the basic values like block, inline, and none.

CSS Tricks felt more design focused and easier to read than MDN. It explained the property in a way that felt more practical, especially if someone is building layouts and just wants to understand how it affects the page. The freeCodeCamp page was more like a lesson or tutorial than a reference page. It was helpful, but it focused more on a specific part of display instead of giving a full reference for every value.

What should a good code reference page offer?

I think a good code reference page should explain the topic clearly, show examples, and make it easy to scan for important information. It helps when a page shows the syntax, common values, and what each one does without making it confusing. I also think examples matter a lot, especially for HTML and CSS, because seeing code makes it easier to understand than just reading definitions.

Another useful feature is having pages that are organized well. If the page is too crowded or too technical right away, it gets harder to use. It is also helpful when a site includes browser support, notes about common mistakes, and little demos that show what the code actually does.

Which references stood out?

The one that stood out the most to me was MDN because it was probably the most complete and reliable, even though it was a little more technical. W3Schools stood out for being the easiest to read quickly. CSS Tricks was probably the most balanced because it felt clear but still useful. The weakest one for this topic was probably the freeCodeCamp article, not because it was bad, but because it felt more like a lesson than a full reference page.
